## 在家、没有头显时可做的测试

1. 复制完整工程的 `Assets`、`Packages`、`ProjectSettings`，保留所有 `.meta`，用相同 Unity 版本打开；`Library`、`Temp`、`Logs` 可由 Unity 重建。All-in-One 首次解析需要联网下载依赖。
2. 打开 `Main.unity` 并进入 Play。只看到 Game 窗口画面不等于 VR 追踪已经通过验证。
3. 点击 Game 窗口获取键盘鼠标输入。未检测到 XR 时，按 `F1` 显示/隐藏桌面调试面板；按住鼠标右键转动视角；左右方向键转动视角。
4. 当前没有实现桌面 WASD 行走。桌面视角、面板、模型和独立计算逻辑可用于基础检查，不能替代头显六自由度测试。
5. 加速度实验脚本已有 Space 主操作、R 重置、Tab 切换参数；具体效果取决于当前实验状态。气体、变压器实验使用已有桌面参数面板。
6. 串口、头显和控制器缺失时，不把设备缺失当作实验数学模型测试失败；也不要直接禁用或删除原实验对象来隐藏问题。当前无硬件路径仍有串口扫描逻辑，不能宣称已经实现完整硬件模拟。

## 实验室 VR 连接与操作

1. USB 连接 Quest 3，Meta Horizon Link 的 Devices 页面确认头显 Active，唤醒左右手柄。
2. 在头显内启动 Quest Link，进入本机的 PC VR 界面；这与查看一块电脑桌面窗口不同。
3. Unity 打开 Main 后进入 Play，不能处于 Pause。若先 Play 后连接头显，停止后重新 Play。
4. 头部转动、现实走动应改变相机姿态；移动手柄应改变虚拟手部姿态。
5. `LaboratoryPlayerView` 已加入：左摇杆按视线方向行走 1.5 m/s，右摇杆 30° 分段转向，回中后可再次转向；死区 0.2；CharacterController 处理人工移动碰撞。未完成实机验收，不能视作已验证功能。

## 追踪故障的真实状态

实测曾出现：Unity XR 上报的头部位置/角度变化，但 CenterEyeAnchor 始终零旋转，`OVRManager.OVRManagerinitialized=False`，相机固定在原位置；这解释了只能看正前方及摇杆不生效。曾发现同一进程加载多份 OVRPlugin。重启和统一 SDK 后仍需重新验证，不能仅凭 FOCUSED 或有图像输出就宣布修复。

验收至少要同时满足：OVRManager 初始化成功；原始头部姿态和相机姿态随转头变化；左右手柄有效；摇杆能移动/转向且不穿过有碰撞体的墙；取下头显或打开系统菜单时停止人工移动。基础诊断暂位于 `Assets/Editor/QuestTrackingDiagnostics.cs`，输出 `Validation/QuestTrackingDiagnostics.log`，是临时只读采样工具，不是正式玩法。

## 2026-11-07 URP Shapes 文本池修复

当前磁盘配置为 URP 17.3.0；Graphics 默认管线及保存的 Ultra 质量等级使用 `Assets/Settings/New Universal Render Pipeline Asset.asset`，其余五个质量等级使用 `Assets/URPDefaultResources` 内的管线资产。

已发现两个 Renderer 的 `m_RendererFeatures` 原本均为空。Shapes 自动文本随相机回调申请，`DrawCommand.Dispose()` 只提交命令，文本要经过 Shapes Render Pass 清理才归还；缺失 Feature 会使正常的消费、归还入口缺失。现已给两个 Renderer 添加启用的 `ShapesRenderFeature`。现有 Shapes Pass 未实现 `RecordRenderGraph()`，因此启用 URP Compatibility Mode，并为当前 Windows Quest Link 对应的 Standalone 目标补齐 `URP_COMPATIBILITY_MODE` 符号；未升级插件或修改 PackageCache。

对 Shapes 加了两处失败保护：分配失败不把 null 登记到活动字典；绘制前若 TMP 实例无效则跳过。池上限判断改为 `>= 1000`，没有提高上限。未改动坐标轴、字体资产、实验逻辑、XR 或 Meta SDK 配置。Unity 导入时自动补写全局 URP 资产的 `m_FallOffLookup` 资源引用。

编辑器验证：当前为带有用户未保存改动的 `Assets/Scenes/Main_URP_Debug.unity`，未保存或切换场景，未进入 Play。Unity 完成脚本重载，采样查询确认 `CompatibilityMode=True`。约 22.4 秒内记录 6,660 次 begin/end 相机回调，37 个采样点的文本池总数稳定为 11，活动数与待渲染命令数均为 0，观察期间新增 Shapes 错误为 0。这支持编辑器工作负载下命令清理与池归还恢复；不表示所有字体、完整 Play 场景或头显显示已验收。仍观察到 TIMES SDF 静态字体图集缺字/不可读警告，未在本次扩大修改字体。
